# Jeddah Guide 🏖️

دليلك السياحي الشامل لاكتشاف أفضل الأماكن في جدة - عروس البحر الأحمر

## 📋 نظرة عامة

**Jeddah Guide** هو تطبيق ويب سياحي وترفيهي يساعد المستخدمين على:
- اكتشاف الأماكن السياحية والترفيهية في جدة
- البحث والفلترة حسب الفئة، السعر، والنوع (داخلي/خارجي)
- حفظ الأماكن المفضلة
- بناء خطة يومية للزيارة
- الحصول على اقتراحات حسب الطقس
- معرفة تفاصيل كل مكان مع الموقع والتقييمات

## ✨ المميزات الرئيسية

### 1. الصفحة الرئيسية
- عرض بطاقة الطقس الحالي في جدة
- اقتراحات ذكية حسب الطقس (أماكن داخلية إذا كان الجو حار)
- عرض الفئات المختلفة
- أماكن مميزة (تقييم 4.7+)
- روابط سريعة للمفضلة والخطة

### 2. صفحة الأماكن
- **بحث ذكي**: ابحث بالاسم، الوصف، أو الموقع
- **فلاتر متعددة**: الفئة، السعر، النوع
- عرض عدد النتائج
- تصميم responsive

### 3. تفاصيل المكان
- معلومات تفصيلية
- زر حفظ في المفضلة
- زر إضافة للخطة
- عرض الأماكن القريبة

### 4. المفضلة والخطة اليومية
- حفظ الأماكن المفضلة
- تنظيم الخطة حسب الوقت
- إدارة الأماكن

## 🗂️ البيانات

يحتوي التطبيق على **20 مكان** في جدة موزعة على:
- أماكن تاريخية
- شواطئ وكورنيش
- مولات
- متاحف
- كافيهات ومطاعم
- أماكن ترفيهية

## 🛠️ التقنيات المستخدمة

- React 18
- Vite
- React Router DOM
- Lucide React (الأيقونات)
- LocalStorage

## 📦 التثبيت والتشغيل


## 📱 الصفحات

- `/` - الرئيسية
- `/places` - الأماكن
- `/place/:id` - تفاصيل المكان
- `/favorites` - المفضلة
- `/plan` - الخطة
- `/login` - تسجيل دخول
- `/register` - تسجيل
- `/profile` - الملف الشخصي
